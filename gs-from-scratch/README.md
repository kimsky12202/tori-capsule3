# 가우시안 스플래팅 밑바닥부터 (Gaussian Splatting from scratch)

세르딕(SERDIC) 입사 준비 + 3D Gaussian Splatting을 **직접 구현하며** 완전히 이해하기 위한 학습 프로젝트.

라이브러리에 의존하지 않고 **forward(splatting) 렌더러와 최적화 루프를 손으로 짜는 것**이 목표다.
2D에서 원리를 100% 이해한 뒤 3D로, 그리고 실제 학습 파이프라인(COLMAP → train → 뷰어)으로 확장한다.

---

## 0. 왜 이걸 하는가 — 세르딕(SERDIC)과의 연결

세르딕은 **웹 기반 디지털 트윈(Digital Twin)** 을 만드는 산업 DX/AI 스타트업이다.
핵심 비즈니스는 *실제 시설·공장을 3D로 복원해 웹에서 실시간으로 시각화*하고,
CCTV·IoT 센서·시설 데이터·AI 이벤트·시뮬레이션을 그 위에 얹는 것.

> 즉 "현실 공간 → 사진/영상 → 실시간으로 도는 포토리얼 3D" 가 정확히 회사의 심장이다.
> **가우시안 스플래팅은 바로 이 일을 가장 잘하는 최신 기술**이라서 면접에서 물어본 것.

| 세르딕이 필요로 하는 것 | 가우시안 스플래팅이 주는 것 |
|---|---|
| 실제 공간의 포토리얼 3D 복원 | 사진 수십~수백 장 → 사실적인 3D 장면 |
| **웹에서 실시간** 렌더링 | 래스터화 기반 → 100+ FPS, WebGL/WebGPU로 구동 |
| 가벼운 전송/저장 | NeRF보다 다루기 쉬운 명시적(explicit) 표현 |
| 디지털 트윈 위 데이터 결합 | 명시적 점 집합이라 좌표·편집·합성이 쉬움 |

## 1. 면접용 핵심 정리 (이것만은 자신 있게)

> 📄 **예상질문 30+개와 모범답안**: [interview_prep.md](interview_prep.md)

### 한 문장 정의
> 가우시안 스플래팅은 **여러 장의 사진으로부터 3D 장면을 수백만 개의 3D 가우시안(반투명 타원체)으로 표현**하고,
> 이를 화면에 **투영→정렬→알파 블렌딩하는 래스터화 방식**으로 **실시간 렌더링**하는 신규 시점 합성(novel view synthesis) 기법이다.

### NeRF와의 차이 (가장 자주 나오는 질문)
| | NeRF | 3D Gaussian Splatting |
|---|---|---|
| 표현 | **암시적(implicit)** — MLP 신경망이 (x,y,z,방향)→(색,밀도) | **명시적(explicit)** — 3D 가우시안들의 집합 |
| 렌더링 | 레이마칭(ray marching) volume rendering | **래스터화(splatting)** — 화면에 투영 후 블렌딩 |
| 속도 | 느림 (학습 수 시간, 렌더 느림) | **빠름 (학습 수 분~수십 분, 렌더 실시간 100+ FPS)** |
| 편집/통합 | 어려움 | 쉬움 (게임엔진·웹에 바로) |

핵심: **"명시적 표현 + 래스터화 = 실시간"** 이 한 줄이 면접의 정답.

### 가우시안 하나의 구성 (파라미터)
1. **위치 μ** (3) — 중심 좌표 (x, y, z)
2. **공분산 Σ** — 타원체의 크기/방향. 학습 안정성을 위해 `Σ = R S Sᵀ Rᵀ`로 분해
   → **스케일 S**(3) + **회전 R = 쿼터니언**(4)
3. **불투명도 α** (1)
4. **색 = 구면 조화 함수(Spherical Harmonics)** — 시점에 따라 변하는 색(반사光 표현). 보통 3차 → 48
→ 가우시안 1개 ≈ **약 59개 파라미터**

수식: 3D 가우시안 `G(x) = exp(-½ (x-μ)ᵀ Σ⁻¹ (x-μ))`

### 전체 파이프라인
1. **입력**: 한 장면을 여러 각도에서 찍은 사진들
2. **COLMAP (SfM)**: 사진 → 카메라 위치/자세 + 희소 점군(sparse point cloud)
3. **초기화**: 점군의 각 점을 가우시안 하나로
4. **미분 가능 렌더링 + 최적화**: 각 학습 뷰로 렌더 → 실제 사진과 비교(L1 + D-SSIM) → 역전파 → Adam으로 모든 파라미터 갱신
5. **적응적 밀도 제어(Adaptive Density Control)**: 부족한 곳은 가우시안 **복제/분할(clone/split)**, 쓸모없는 건 **제거(prune)** → 10만 → 수백만 개로 성장
6. **출력**: `.ply`(또는 `.splat`) 파일 → 뷰어가 실시간 렌더

### 렌더링(splatting)이 실시간인 이유
1. 각 3D 가우시안을 2D 이미지 평면에 **투영** → 2D 타원("splat") (카메라 야코비안으로 공분산 투영, EWA splatting)
2. 깊이로 **정렬**
3. 앞→뒤로 **알파 블렌딩**(over compositing)
4. 화면을 **16×16 타일**로 나눠 GPU에서 **병렬** 처리 ← 실시간의 비결
5. 위 전 과정이 **미분 가능** → 학습 때 gradient가 흐름

### 한계 (정직하게 말하면 가점)
- 파일/메모리 큼(수백만 가우시안) → 압축 연구 활발 (SOGS 등)
- 관측 안 된 영역에 "floater" 아티팩트
- 조명 분리(relighting)·동적 장면 기본 미지원
- COLMAP이 무텍스처/반사 표면에서 카메라 추정 실패 가능

### 최신 동향 (2024–2025, "요즘 흐름 아세요?" 대비)
- **2DGS / Mip-Splatting**: 표면 정확도·안티앨리어싱
- **SuGaR / GOF**: 가우시안에서 메시 추출
- **압축**: 용량 대폭 축소
- **4D / Dynamic GS**: 움직이는 장면
- **Gaussian SLAM** (MonoGS, SplaTAM): 실시간 매핑 ← *디지털 트윈과 직결*
- **DreamGaussian**: text→3D 생성

> 원논문: Kerbl et al., *"3D Gaussian Splatting for Real-Time Radiance Field Rendering"*, SIGGRAPH 2023 (INRIA).

## 2. 직접 구현 커리큘럼 (이 레포의 로드맵)

| 단계 | 내용 | 배우는 것 | GPU |
|---|---|---|---|
| **Phase 1** ✅ | **2D 가우시안 스플래팅** — 이미지 1장을 가우시안으로 재현 | splatting + 미분가능 최적화의 핵심 | 불필요(CPU) |
| Phase 2 | 3D로 확장 — 카메라 투영, 멀티뷰 | 3D→2D 투영, 공분산 투영, 깊이 정렬 | CPU 가능(소규모) |
| Phase 3 | 실제 데이터 학습 — COLMAP, densification, SH | 전체 학습 파이프라인 | 권장 |
| Phase 4 | 실시간 뷰어 (웹) — `.ply`/`.splat` 렌더 | WebGL/WebGPU 실시간 렌더, **세르딕과 직결** | 불필요 |

지금은 **Phase 1**. 여기서 "가우시안이 무엇이고, 어떻게 화면에 그려지고, 어떻게 학습되는가"를 손으로 만든다.

## 3. 실행 방법

```bash
cd gs-from-scratch
source .venv/bin/activate          # 가상환경 (setup이 만들어 둠)

cd phase1_2d
python train_2d_gs.py                          # 합성 타겟 (의존성 없음)
python train_2d_gs.py --image 내사진.jpg        # 내 사진을 가우시안으로 재현
python train_2d_gs.py --num-gaussians 1500 --size 128 --steps 600
```

결과는 `phase1_2d/outputs/` 에:
- `target.png` — 목표 이미지
- `step_XXXX.png` — 학습 중간 결과
- `progress.gif` — 점들이 점점 이미지를 닮아가는 과정
- `compare_target_vs_render.png` — 타겟 vs 최종 렌더 비교

### `train_2d_gs.py`에서 꼭 볼 코드
- `Gaussians2D` : 가우시안의 **학습 파라미터** 정의 (위치/스케일/회전/색/불투명도/깊이)
- `inv_cov()`   : 공분산 `Σ = R S Sᵀ Rᵀ` → `Σ⁻¹` 를 직접 계산
- `render()`    : **splatting 그 자체** — 투영(2D라 생략)→가우시안 평가→정렬→알파 블렌딩
- 학습 루프     : `loss.backward()` 한 줄로 미분, Adam으로 갱신
